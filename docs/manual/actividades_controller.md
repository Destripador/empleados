# Controlador de Actividades

El controlador `ActividadesController` es responsable de gestionar las actividades de los empleados en Nextcloud. Proporciona métodos para obtener, crear, modificar y eliminar actividades, así como exportar e importar datos.

## Métodos Disponibles

### GetActividades()

**Descripción:** Obtiene la lista de todas las actividades.

**Parámetros:**
- Ninguno

**Retorno:**
- `DataResponse`: Lista de actividades en formato JSON.
